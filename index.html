ICD360S e.V. Mitglieder — Flatpak Repository

Auto-Update für die Mitglieder-App. Einmal hinzufügen, danach läuft flatpak update automatisch beim nächsten Release.

Installation

flatpak remote-add --user --if-not-exists icd360s-mitglieder \
  https://icd360s-e-v.github.io/mitglieder/icd360s-mitglieder.flatpakrepo
flatpak install --user icd360s-mitglieder de.icd360s.Mitglieder

Update

flatpak update --user
